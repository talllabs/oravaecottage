# Oravae Island Bungalows

A multi-page tourism website for Oravae Island Bungalows, Solomon Islands.

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS

## Deploying to Vercel

1. Go to [vercel.com](https://vercel.com) and sign in
2. Click **"Add New Project"**
3. Import this GitHub repository
4. Vercel will auto-detect Next.js — just click **Deploy**
5. Done!

No build configuration needed.

## Pages

| Route | Page |
|-------|------|
| `/` | Home — hero, booking bar, intro, bungalow previews, testimonials |
| `/about` | About Us — story, photos, testimonials |
| `/bungalows` | Bungalows — The Cottage, The Penthouse, The Treehouse with booking widgets |
| `/activities` | Activities — surfing, diving, snorkelling, fishing, village tours |
| `/gallery` | Gallery — categorised lightbox gallery (Location / Accommodation / Activities) |
| `/location` | Location — illustrated SVG map, getting there guide |
| `/enquiries` | Enquiries — full booking enquiry form |

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
